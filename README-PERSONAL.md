# AntiStealer 0.3.3 Personal

Этот пакет предназначен для установки на собственные Windows 10/11 x64 компьютеры. Он не содержит неподписанный kernel-драйвер и не отключает Secure Boot, Defender или проверку подписей.

## Установка

1. Установите **.NET Desktop Runtime 9 x64**, если его ещё нет: <https://dotnet.microsoft.com/download/dotnet/9.0>.
2. Распакуйте архив полностью в обычную папку.
3. Запустите `Install-AntiStealer.cmd` и подтвердите UAC.
4. Откройте AntiStealer через меню Пуск и проверьте, что служба отображается как активная.
5. На каждом компьютере отдельно добавьте официальный TG WS Proxy кнопкой **«Доверять файлу…»**. Доверие закрепляется за SHA-256 и не переносится между обновлёнными файлами.

Установщик добавляет TXC-интерфейс уведомлений в автозапуск. При тревоге появляется компактная чёрно-жёлтая карточка справа снизу; процесс уже заблокирован, а щелчок по карточке открывает подробности и действия. При скрытии окна отдельная карточка подтверждает, что защита продолжает работать в трее. Меню значка в трее следует системной светлой или тёмной теме Windows.

Proxifier разрешается автоматически только при действительной Authenticode-подписи издателя Initex. Repack/crack-версии не разрешаются.

## Что работает без kernel-драйвера

- постоянная LocalSystem-служба;
- поведенческий анализ процессов и исходящих TCP-соединений;
- блокировка подозрительного EXE через Windows Firewall;
- восстановление отключённых профилей и удалённых блокирующих правил;
- контроль SHA-256 и Authenticode у браузеров, Telegram, Steam, Discord и AntiStealer;
- Security Audit/SACL для хранилищ браузеров, Telegram, Discord, Steam, DPAPI и кошельков;
- предупреждение, завершение процесса и карантин.

Ограничение: Security Audit сообщает о доступе после открытия файла. Служба старается заблокировать сеть до отправки данных, но гарантировать это при очень быстрой атаке не может. Перехват до открытия файла обеспечивает только подписанный minifilter.

## Удаление

Запустите `Uninstall-AntiStealer.cmd` и подтвердите UAC. Журнал и карантин в `C:\ProgramData\AntiStealer` намеренно сохраняются.
